# work-package-specs rev8 → rev9 版本差异说明

> 本文档对比 **rev8（现行版 `work-package-specs.mediawiki`）** 与 **rev9（试行版 `work-package-specs-v2-draft.mediawiki`）** 的差异，供各方核对。
>
> 版本状态：rev9 经 CGC 会议 2026-08-30 决议先行合并为**试行版**，于下一次 PoWh 统计（2026-09 起）实际运行；正式批准签署待试运行后回填。
> 会议记录：https://github.com/Jouleverse/open-meetings/blob/main/core/CGC20260830.md

---

## 一、总体定位变化

| 维度 | rev8 | rev9 |
|---|---|---|
| 文档性质 | 规范（规范 + 零散操作指引） | 规范 + 操作指引（双重属性） |
| 结构 | 按「标准/非标/混合」三级分类 WP | 废除三级分类，每个 WP 内部区分「标准化工作项 / 非标工作项」 |
| 颗粒度 | WP 级 | 细化到**工作项**级 |
| 状态标注 | 无统一状态标注 | 每个 WP 标注 🟢活跃 / ⏸暂停 / 🗄仅运维 / 💤非活跃 |

## 三、规则性变化（实质规则差异）

### 1. WP-13 知识库规则（v2 关键变更）
- **rev8**：知识库内容贡献计入「相关具体工作所属的 WP」（如节点搭建文档报 WP-7）；仅编辑 review & merge 计入 WP-13。
- **rev9**：知识库（how.jouleverse.com / wiki.jouleverse.com，repo 含 `Jouleverse/how` 与 `Jouleverse/wiki`）的**内容贡献、功能开发、编辑 review & merge 一律计入 WP-13**。废除旧版"内容贡献计入相关 WP"表述。

### 2. WP-15 治理范围（v2 关键变更）
- **rev8**：WP-15 侧重多签/Wrapper/veJ/timelock/Governance 等合约 + tokenomics 记账。
- **rev9**：**明确纳入 JIP/JEEP 提案撰写与治理机制研究**，消除历史上同类工作在 WP-3 与 WP-15 间漂移的歧义。

### 3. 非标上报截止时间
- **rev8**：无成文时限（仅"月初通知"口头约定）。
- **rev9**：明确为**次月 5 日 24:00**（v2 明确化）。
  - ⚠️ 注：本地 SOP/统计时间规则.md 写「15 日 24:00」，与 rev9 正文「次月 5 日」存在新旧两说并存，8 月统计按旧规 9/15 执行（详见 8 月表附注〇-2）。

### 4. 非标上报必须附产出物链接
- **rev8**：未强制（仅建议）。
- **rev9**：**强制附产出物链接（PR/issue/文档/链上 tx），无链接不计数**，统计员有权剔除。

### 5. WP-4 / WP-5 暂停
- **rev8**：WP-4（社群建设）、WP-5（JNSDAO）为活跃 WP，有明确激励标准。
- **rev9**：**WP-4、WP-5 标注 ⏸ 暂停**（2026.8 起），保留规范文本备查，恢复须经 CGC 决议。

### 6. WP-2 节点清单依据
- **rev8**：节点清单以「审计员月度节点报告」为默认（隐含）。
- **rev9**：**明确**以审计员月度节点报告为准（改动最小）；中期可结构化 nodes.yaml 交叉核验（改进建议，未生效）。

### 7. 统计表列名统一
- **rev8**：列名未强制统一。
- **rev9**：**统计表列名统一为 `WP-{N} {全名}`**，与 spec 正文一致；当月有统计的 WP 才建列。

### 8. WP-6 会务称谓（微尘 J-53 提案，社区现行口径）
- 费率表与会议纪要表格存在两套叫法。rev9 正文沿用「预定会议 0.5h / 参会签到 0.5h / 议题征集&纪要整理(书记员) 2h」；**社区提案统一为「会议预定 0.5h / 会议主持 2h / 会议发言 0.5h」**，三处列名（费率表/纪要表/raw 溯源表）逐字一致。
  - 该称谓统一提案详见 CGC 2026-09-13 微尘 J-53 发言纪要。
